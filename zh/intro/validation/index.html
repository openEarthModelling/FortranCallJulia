    验证¶

    本站出现的每个标志性数字都来自一道真实运行过的验收门，而不是设计意图。三道头条门锚定整个项目——其中第二道本身捆着四道内部门：每道门都把桥与一个独立基线相比，而且只有当双方运行同一个钉死的 Julia 1.12.7 时才算数——跨 Julia 版本的比较测的是版本漂移，不是桥。

    门一：CJ 爆速¶

    反应流收官示例（reacting_flow）模拟 Chapman–Jouguet 爆轰：Fortran Euler 驱动器 + 内嵌 Clawpack 核，经 Strang 分裂与 Catalyst 化学耦合。

    量 值
    仿真 CJ 爆速 7.12391
    解析 CJ 爆速 7.12470
    偏差 0.011%

    仿真波速与解析 CJ 值的偏差仅 0.011%，意味着算子分裂、分裂内部的桥穿越、以及 Julia 化学积分器，全部在离散误差范围内保持物理不损。

    门二：桥接对原生——四道内部门零偏差¶

    GRI 点火算例（gri_ignition）运行两遍：一遍过桥，一遍作为原生 Julia 基线。四道内部验收门比较输出。

    设定 结果
    双方 Julia 版本 1.12.7（钉死）
    比较的门数 4
    发现的偏差 0
    残差 < 1e-12

    低于 1e-12 的残差已到浮点非结合性消失、精确一致开始的量级：桥没有改变任何算术。

    为什么版本钉死是指标的一部分

    早先一次对拍失败，原因与桥毫无关系：一个版本垫片把 Julia 静默解析到了与桥内嵌版本不同的 minor 版本上，基线随之漂移。自那以后，每次比较的双方都钉死同一个 1.12.7 二进制。

    门三：GRI 点火延迟¶

    同一套机构计算 GRI-Mech 3.0 均相混合气（53 物种、325 反应）的点火延迟：

    • t_ign = 1.1075 ms，取 argmax |dT/dt|——最大放热率时刻，这是不依赖阈值约定的标准锐利定义。

    从 325 反应的网络算出物理上合理的点火延迟，是一次端到端检查：机理解析（ChemMechSim.jl，已开源；本次验证使用 v1.2.0）、网络构建（Catalyst）、刚性积分（OrdinaryDiffEq）、以及数据回流 Fortran 数组的通路。

    汇总¶

    指标 值 验收门
    CJ 爆速 7.12391 对 7.12470，偏差 0.011% reacting_flow，Clawpack1d + Strang 分裂
    桥接对原生 4 门 0 偏差，残差 < 1e-12 gri_ignition，双方同钉 1.12.7
    GRI 点火延迟 t_ign = 1.1075 ms（argmax abs(dT/dt)） gri_ignition，GRI-Mech 3.0，ChemMechSim.jl v1.2.0

    复现步骤、计时方法与交付形态阶梯（JIT 17.3 s → sysimage 1.90 s → AOT 首调约 12 μs）见用户指南与开发者附件。
